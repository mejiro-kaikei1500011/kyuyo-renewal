# 給与計算ツール（給与明細・賃金台帳・振込一覧）

社員の給与・賞与を入力すると、給与明細・賃金台帳・振込一覧・源泉徴収票（参考）を作成して印刷できる静的サイトです。サーバーは不要で、GitHub Pages などでそのまま公開できます。

## 機能

- **給与明細**：基本給・時間外手当・通勤手当(非)・不就労控除・手当・その他控除を入力すると、社会保険料・雇用保険料・所得税を計算し、給料明細書の形式で表示・印刷します。賞与明細にも対応します。
- **前月コピー**：前月の手当・控除・金額を当月に引き継ぎます（日数・時間は引き継ぎません）。
- **社員**：氏名・会社名・社会保険の加入、雇用保険（未加入／一般の事業／農林水産・清酒製造／建設の事業）、40歳以上（介護保険）、扶養人数、甲欄・乙欄の区分、都道府県（健康保険料率）を登録します。標準報酬月額（等級）は、適用開始年月ごとに履歴として指定できます（指定がない月は等級表で自動決定）。
- **振込一覧**：対象年月の給与・賞与の差引支給額を一覧にして印刷します（振込先の口座情報は扱いません）。
- **賃金台帳**：社員ごと・年ごとに、月別の支給・控除を一覧にして印刷します（賞与も含みます）。
- **源泉徴収票（参考）**：年間の記録から概算の項目を並べて印刷します。正式な様式ではなく、年末調整の結果とは一致しません。
- **メール・LINEで送る**：明細の文章を、メール作成画面またはLINEの共有画面に渡します。送信前に確認ダイアログを出します。
- **データの書き出し／読込**：JSON で保存・復元できます。

## 料率・税額の改定について

料率と税額の数値はすべて `data/rates.js` にまとめています。改定時はこのファイルだけを書き換えてください（`js/` の計算コードは変更不要です）。

- `effectiveFrom`・`asOf`：適用開始日と最終確認日を更新する
- `health`：健康保険料率。`byPrefecture` に都道府県ごとの値を入れます（東京都 9.85%、埼玉県 9.67%、神奈川県 9.92%。未確認の県は `null` のままで、手入力か全国平均 9.90% で計算します）
- `health.childSupportPercent`・`health.childSupportFrom`：子ども・子育て支援金（0.23%、2026年5月支払分から）
- `care`・`pension`：介護保険料率（1.62%）・厚生年金保険料率（18.3%）
- `employmentPermille`：雇用保険の労働者負担（‰）
- `commuteNontaxableLimit`：通勤手当の非課税限度額（月額・改定時は要確認）
- `withholdingMonthly`：源泉所得税の月額表（国税庁「源泉徴収税額表」令和8年分の甲欄・乙欄）。`bands` は 105,000円以上の帯、`exact` は表の固定点、`formulaKou`・`formulaOtsu` は固定点の間の式です。年が変わったら表を差し替えてください。
- `incomeTax`：賞与の所得税（年額の税額差による概算）に使う基礎控除・扶養控除・給与所得控除の最低保障額・税率区分（`brackets`）・復興特別所得税
- `healthGrades`・`pensionGrades`：標準報酬月額の等級表
- `bonusCap`：賞与の標準賞与額の上限

## 所得税の計算

- 給与の源泉所得税は、社会保険料等控除後の金額（課税対象額から健康保険・介護保険・厚生年金・雇用保険を引いた額）を月額表に当てはめて求めます。扶養人数は甲欄の列（0〜7人）に使い、乙欄は扶養人数を使いません。
- 月額表の帯や固定点の値をそのまま使い、固定点の間は表の式（基準の税額＋超過額×率、円未満切捨て）で求めます。105,000円未満の甲欄は0円、乙欄は3.063%です。
- 賞与の所得税は、参考月給と賞与を合わせた年額の税額差による概算です。年末調整は含みません。

## 注意

- 障害者・寡婦などの控除、年末調整は反映していません。
- 月額表の 1,710,000円以上の欄（式と固定点の境界）は国税庁の表の抜粋を写したもので、実際の表と照合して確認してください。
- 住民税は計算・表示していません。
- 社会保険料は等級表に基づく計算ですが、実際の決定は年金事務所・健康保険組合の通知に従ってください。
- 入力データはブラウザの localStorage にのみ保存されます。サーバーには送信されません。ブラウザのデータを消去すると失われるので、定期的に「データ書き出し」を行ってください。
- 計算ロジックの確認：`node tests/calc.test.js`、`node tests/calc.extra.test.js`
- 画面の確認（jsdom が必要）：`node build/bundle.js` で `dist/preview/index.html` を作ってから、`node tests/ui.check.js`

## 構成

```
index.html          画面（給与明細・社員・賃金台帳・振込一覧・源泉徴収票）
style.css           画面と印刷用のスタイル
data/rates.js       料率・税額・等級表（改定時に編集）
js/calc.js          計算ロジック（DOM に依存しない純粋関数）
js/app.js           画面制御・データ保存
tests/calc.test.js        計算の検算テスト
tests/calc.extra.test.js  料率選択・支援金・通勤手当などの検算テスト
tests/withholding.test.js  月額表（甲欄・乙欄）の検算テスト
tests/ui.check.js         画面の動作確認（jsdom）
build/bundle.js     1ファイル版（dist/preview/index.html）を作る
```

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、Branch を `main`・フォルダを `/ (root)` に設定すると公開されます。
